# 先看成片、再生成并回填旁白

本阶段不剪画面、不加 BGM。原视频生成并通过基础 QC 后，才确定旁白时长与速度。

## 1. 标记真实可用窗口

逐镜播放并记录所有现场对白的起止时间。先用带词级或句级时间码的语音识别与人声活动检测找候选区间，再播放候选区间及其边界进行复核。旁白目标窗口必须没有人物开口对白，并与旁白语义对应。保留合理动作声、环境声和句间呼吸。提示词预计时间、波形峰值、静音检测结果只能辅助定位，不能单独证明“这里没有对白”。

每个确认后的对白区间前后默认扩展 0.35 秒作为交界保护区；语速急促、多人抢话或尾音较长时扩大保护区。无法取得可靠时间码、无法判断声音是否为对白，或无法完成播放复核时，停止在 cue 规划阶段并向用户报告，不生成旁白版视频。

cue sheet 至少包含：`cue_id`、`narration_text`、`source_start`、`source_end`、`target_start`、`target_end`。根级必须包含 `dialogue_timeline`，其中 `basis` 固定为 `actual_video_verified`，并列出实际对白区间。确认整镜没有对白时也必须提供空数组，不能省略时间轴。

## 2. 生成前容量门禁

拆镜阶段先估算：`对白秒数 + 旁白秒数（最高 1.25 倍速）+ 交界保护量`。结果超过镜头时长就继续拆镜，并在提示词中为旁白明确安排“无对白、无人开口、无人对口型”的画面占位。不得把音频空间问题留到生成后解决。

下载原视频后重新计算真实容量：将带保护区的对白区间从视频中扣除，只用剩余窗口计算旁白可用秒数。旁白必须保持剧情顺序；不能为了塞入空档而把后发生的旁白提前到不对应的画面。

## 3. 计算安全语速

运行 `narration_speed.py`，传入旁白文本和窗口秒数。默认 1.1，范围 0.95–1.25：默认速度能放下则不变；否则只提到刚好放下的值。若估算超过 1.25，停止并报告所差秒数。

估算只用于生成前。Voice Clone 完成后必须测量真实语音边界；实测放不下时可在范围内重算并重新生成旁白音频，但不得重生视频、删句、叠对白或变速画面。

## 4. 集级 WAV 与逐镜回退

优先把同集旁白按原顺序生成 `{集数}.wav`，用自然停顿、静音检测和试听确定每段 `source_start/end`，禁止固定平均切割。若不同分镜要求的速度差异导致单一速度不能兼容，改为逐镜生成 `{集数}-{分镜号}.wav`。同一段跨镜时只在自然停顿处分割，无法无损切分则中断。

Voice Clone 文本只含旁白正文，不含对白、角色名、场次标题、动作说明。双引号只是判断线索，必须结合说话人与上下文。

## 5. 固定混音

把 cue 写入 JSON 并调用 `scripts/mix_narration.py`。工具会：复制视频流；把原音轨作为底声；仅在旁白目标窗口轻度降低底声；切取、淡入淡出并延迟旁白片段；输出 48 kHz、立体声、192 kbps AAC。

示例：

```json
{
  "video": "D:/output/1-1.0.MP4",
  "narration": "D:/audio/1.wav",
  "output": "D:/output/1-1.0(OV).MP4",
  "duck_gain": 0.55,
  "dialogue_timeline": {
    "basis": "actual_video_verified",
    "guard_seconds": 0.35,
    "intervals": [
      {"start": 6.2, "end": 8.6, "speaker": "Mara", "text": "Jace?"}
    ]
  },
  "cues": [
    {"cue_id": "EP01-S01-N01", "narration_text": "Narration text", "source_start": 0.0, "source_end": 3.8, "target_start": 1.2, "target_end": 5.0}
  ]
}
```

`mix_narration.py` 在创建输出前强制执行：真实时间轴声明存在；对白区间有效；旁白目标窗口不互相重叠；旁白与任一扩展后的对白区间零交叉；源片段不长于目标窗口；所有区间均在媒体时长内。任一条件失败就停止，不能通过调低 `duck_gain` 绕过。原视频、WAV、cue sheet 均保留，输出为同目录 `{集数}-{分镜号}.{抽卡序号}(OV).MP4`。

## 6. 放不下时的唯一处理

实测旁白在 1.25 倍速下仍无法按剧情顺序放入无对白窗口时，不输出 `(OV)`：报告缺少的秒数和冲突区间，让用户选择重新拆镜/生成更合适的原视频，或明确授权改写旁白。未经用户明确授权，不删字、不超速、不挪到错误画面，也不允许有意叠对白。

## 7. 完成检查

逐段试听开头、结尾和对白交界；确认无截字、重叠、爆音、错误文本；合理音效仍在。监听时一旦出现对白与旁白同时说话，结果判定为 `FAIL`，即使技术媒体 QC 通过也不能交付。运行媒体 QC 并以原视频为 `--reference-video`，确认总时长、分辨率、帧率和视频流没有意外变化。
